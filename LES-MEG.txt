HJERTEROM – LOKAL KJÆRLIGHETSASSISTENT

Hjerterom gir råd om kjærlighet og relasjoner med Gemma 3 1B gjennom Ollama. Spørsmål går til Ollama på samme Mac, og appen lagrer ikke samtaler.

KOM I GANG – ÉN NEDLASTING
1. Last ned ZIP-filen fra GitHub Releases og pakk den ut.
2. Dobbeltklikk START-ME.command. Hvis macOS spør, velg Åpne.
3. Hvis Ollama mangler, starter fila den offisielle Ollama-installasjonen.
4. Første gang lastes Gemma-modellen ned (omtrent 806 MB) og Hjerterom klargjøres. Dette krever internett.
5. La Terminal-vinduet stå åpent mens du bruker Hjerterom.

SENERE BRUK
Dobbeltklikk START-ME.command igjen. Stopp serveren ved å lukke Terminal-vinduet.

LOKAL BRUK
Serveren lytter bare på 127.0.0.1 på denne Mac-en. Samtalene finnes bare i nettleserfanen mens den er åpen.

BEGRENSNINGER
- Krever macOS 14 Sonoma eller nyere og internett første gang. Etter oppsett kan Hjerterom brukes offline.
- Modellen er liten for å kjøre lokalt. Den kan misforstå eller gi generelle råd; bruk egen vurdering.
- Assistenten er ikke terapeut. Hvis du er utrygg, fortell det til noen du stoler på og kontakt nødhjelp der du befinner deg hvis faren er akutt.

MODELLSIDE
Gemma 3 via Ollama: https://ollama.com/library/gemma3
Ollama for macOS: https://ollama.com/download/mac
